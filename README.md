# Desafío: Literalura, catálogo de libros - Oracle Next Education, Oracle, Alura Latam

Con este proyecto nos conectamos a Gutendex, JSON web API para brindar al usuario una colección de diversos libros, los cuales ya estarán incorporados a nuestra base de datos implementada en PostgreSQL. :nerd_face: :computer:

## :thinking: Como probar:

- En una terminal ejecuta el comando en git: ```git clone https://github.com/fatiperea/literaluraFPerea.git```
- Luego de clonar, accede al proyecto y comienza a probar las funcionalidades disponibles, no se requiere contar con una API-KEY en este caso.
- Asegúrate de contar con los siguientes programas, archivos y versiones:

Java JDK: versión: 17 en adelante -
Download the Latest Java LTS Free

Maven: versión 4 en adelante

Spring: versión 3.2.3 - https://start.spring.io/

Postgres: versión 16 en adelante - PostgreSQL: Downloads

IDE (Entorno de desenvolvimento integrado) IntelliJ IDEA- opcional -
